Privacy Policy

Effective date: August 31, 2026

Dalton Books Bridge (the "Application") is a private, single-user integration that connects its owner's own QuickBooks Online company to bookkeeping software running locally on the owner's personal computer.

What data the Application accesses

With the owner's explicit OAuth authorization, the Application accesses accounting data from the owner's own QuickBooks Online company via Intuit's APIs — for example the chart of accounts, transactions, invoices, bills, vendors, customers, and financial reports.

Where data is stored

All data retrieved by the Application is processed and stored locally on the owner's own computer. OAuth access and refresh tokens are stored in a local configuration file readable only by the owner. No data is transmitted to, stored on, or processed by any server operated by the Application.

What is shared with third parties

Nothing. The Application does not sell, rent, share, or disclose any data to third parties. It has no analytics, no advertising, and no telemetry.

Data about visitors to this website

This website is a static informational page. It does not collect, store, or process any information about its visitors and sets no cookies.

Data retention and deletion

Locally stored data and tokens are retained at the owner's discretion and can be deleted by the owner at any time. Disconnecting the Application from QuickBooks Online revokes its access; local tokens are then deleted.

Changes

This policy may be updated from time to time. The current version is always published at this page.
